# ta-fishing（釣り）

Qbox サーバー向けの釣りスクリプト。水辺ならどこでも釣れて、釣りレベル、5段階のグレード、漁師 NPC の店と買取（相場が動く）、ランキングがある。設計は [[設計案-釣り・採集]]、目次は [[FiveM-Script/README|FiveM-Script 目次]]。

旧名は `tani-fishing`（2026-11-13 に `ta-fishing` へ変えた）。旧名のまま入れているサーバーは、古いフォルダを消してから入れ直す。記録のテーブルも `tani_fishing_players` から `ta_fishing_players` に変わったが、起動した時に新しいテーブルが空で古いテーブルがあれば、記録を自動で写す（古いテーブルは消さずに残す）。漁師の店の ID は `ta_fishing`、相場の GlobalState は `taFishingMarket` になった。

> [!warning] 未確認
> 2026-11-11 に検証サーバー（qbox-server の PR #23）へ旧名の tani-fishing で導入した。FiveM の実機ではまだ動かしていない。サーバーとクライアントの処理は疑似環境で通しで確かめた（下の「テスト」）。NPC の位置、竿の持ち方、水辺の判定は実機で見て直す。

## 遊び方

1. 漁師 NPC（デル・ペロ桟橋、地図の魚のマーク）に話しかけ、漁師の画面の「道具を買う」で釣り竿（15,000円）と釣り餌（40円）を買う。支払いは銀行から。
2. 海・川・湖のそばで水面を向き、インベントリから釣り竿を使う。画面の下にガイドが出る。
3. アタリまで 15〜35秒待つ。アタリが来たら糸の張りのミニゲームになる（下の「糸の張り」）。釣り上げると魚が手に入る。
4. 餌が残っていれば自動で投げ直す。X でやめる。
5. 漁師の画面の「魚を売る」で、その時の相場で売る。売上は現金で受け取る。

`/fishstats` で自分の記録、`/fishrank` でランキングをどこからでも見られる（売る・道具を買うは漁師の前でだけ）。

### 糸の張り

左クリック（またはスペース）を押している間は糸を巻く。巻いている間は張りが上がり、離すと下がる。

- 寄せが100%になれば釣り上げ。離している間は魚に糸を引き戻され、寄せが0%になると逃げられる。
- 魚はときどき暴れる。暴れる前に「魚が首を振った」と出るので、指を離して耐える。暴れている間に巻き続けると、張りが100を超えて糸が切れる。
- 上のグレードほど強く、長く暴れる。レベルが上がると軽くなる（レア Lv10、エピック Lv18、レジェンド Lv25 から）。

自動プレイヤーで試した目安（`tests/test-reel.js`）は次のとおり。0.25秒で反応すれば、どのグレードも 7〜11秒でほぼ釣れる。巻き続けるだけだと、レア以上はほぼ必ず糸が切れる。アンコモンは入門なので、巻き続けても半分ほどは釣れる。

## 仕組み

### 釣りレベル

経験値はグレードごとに入る（コモン5、アンコモン12、レア30、エピック80、レジェンド250）。レベル n から n+1 に要る経験値は `60 + 30 × n`、最大は30。

レベルが上がると、次の2つが変わる。

- 上のグレードが出やすくなる。グレードの重みが1レベルごとに増える（アンコモン+4%、レア+8%、エピック+15%、レジェンド+25%）。エピックはレベル5、レジェンドはレベル10まで出ない。
- 上のグレードの引きが軽くなる。レア（レベル10）、エピック（レベル18）、レジェンド（レベル25）から、糸の張りのミニゲームで魚が弱くなる。

昼の出やすさを設定値から計算すると、次のとおり。疑似環境でレベル30のまま4,000匹釣った結果も、ほぼこの割合だった（レジェンドは0.7%）。

| 釣りレベル | コモン | アンコモン | レア | エピック | レジェンド |
| --- | --- | --- | --- | --- | --- |
| 1 | 70.7% | 22.2% | 7.1% | 0% | 0% |
| 30 | 47.5% | 32.3% | 15.8% | 3.6% | 0.8% |

夜はレア以上の重みが上がる（レア×1.2、エピック×1.3、レジェンド×1.5）。

### 魚とグレード

| グレード | 海 | 淡水 |
| --- | --- | --- |
| コモン | アジ、イワシ | フナ |
| アンコモン | サバ、カサゴ | ブラックバス |
| レア | クロダイ、スズキ | ニジマス、スズキ |
| エピック | ヒラメ | イトウ |
| レジェンド | クロマグロ | 黄金ゴイ |

水面の高さが `Config.FreshwaterMinZ`（3m）より上なら淡水、下なら海として扱う。アラモ湖や貯水池は淡水、海辺の川は海になる。レジェンドを釣ると、サーバー全員に通知が出る。

### 水辺の判定

竿を使うと、前方 8m・12m・5m・16m の順に `TestProbeAgainstWater` で水面を探す。足元から 25m 下までの水面が対象なので、桟橋や岸壁の上からも釣れる。乗車中、泳いでいる間、死亡中は使えない。

### 相場

魚ごとに `Config.Fish` の価格の範囲（例: アジ 200〜320円）があり、その中で動く。

- 20分ごとに、範囲の中央値の±8%で揺れる。中央値へ少しずつ戻る力も働く。
- 1匹売るごとに0.3%下がる。同じ魚をまとめて売るほど安くなり、時間とともに戻る。
- 相場は「今の相場」と売却メニューに、値上がり・値下がりの印つきで出る。サーバーを再起動すると引き直す（保存しない）。

### ランキングと記録

oxmysql の `ta_fishing_players` テーブルに、キャラクターごとの経験値、レベル、釣った数、レジェンドの数、魚ごとの数を保存する。テーブルは起動時に自動で作る（手で流すときは `install/ta_fishing.sql`）。ランキングは経験値順と釣った数順の上位10人。自分の記録では、まだ釣っていない魚を「？？？」で伏せる。

### 不正対策

抽選、餌の消費、魚の付与、売却、記録はサーバーで行う。client は演出と糸の張りのミニゲームだけを受け持つ。

- 投げるとき、サーバーは竿と餌の所持、天候、送られた水面とプレイヤーの距離を確かめる。
- 引き上げは、アタリの時刻より前（0.5秒の余裕）や、30秒を過ぎたものを受け付けない。投げた場所から3m以上動いても逃げられる。1回の投げで受け付けるのは1回だけ。
- ミニゲームの成否は client の申告なので、改ざんされうる。アタリから `Config.Reel.minMs`（2.5秒）より早い成功は受け付けない。1時間に150匹を超えたら付与を止め、サーバーのログに残す。
- 売却は漁師から8m以内でだけ受け付ける。
- 店（ox_inventory のショップ）は場所を持たない登録にしているので、改造クライアントなら離れた場所からも開ける。売るのは竿と餌だけなので、そのままにしている。

## 画面

画面は `html/` の NUI 1枚にまとめてある（2026-11-11 に unslop で作成）。

- **釣りの最中のガイド**: 画面の下の中央に出る。クリックは受け付けない。アタリ待ち（海か淡水、餌の残り）、糸の張り（張り・寄せ・魚までの距離）、釣果（魚の絵、グレード、経験値、レベル）、逃げられた理由を順に出す。使えるキーはいつも一番下の段にある。
- **漁師の画面**: 漁師に話しかけると開く。左に漁師の一言（相場の動きから決まる）と項目、右に中身。項目は、魚を売る（数を選んで売る、全部売る）、今の相場（グレードごと、範囲の中のどこにいるか）、ランキング（経験値と釣った数、自分の行は強調）、自分の記録（レベル、図鑑。まだ釣っていない魚は影だけ）、道具を買う（ox_inventory の店を開く）。Esc で閉じる。

見た目の決まりは次のとおり。

- 方向は「朝の魚市場」。面は落ち着いた灰色で、色は魚の絵とグレードのひし形が持つ。
- グレードは、アイテム画像の右下と同じひし形をグレードの色で塗って示す。
- 差し色は浮きの朱（`#e8590c`）。ガイドの浮き、ランキングの1位、レベルの進行バーにだけ使う。
- 相場の変化は「前回比 +24円」のように、前回の更新との差を円で出す。差にはその間に売られて下がった分も含む。
- 文言に「！」と「…」は使わない。短い文の文末に「。」を付けない。
- レベルは「Lv.12」と書く。数字は等幅で揃える。
- 動きは、アタリ待ちの浮きの上下と、魚が暴れている間のゲージの震えだけ（どちらも状態を表す）。

ブラウザで `html/index.html?view=wait`（`reel` `run` `caught` `fail` `sell` `confirm` `market` `ranking` `record`）を開くと、見本のデータで見た目を確かめられる。魚の絵は `install/images/` から読む。

## 収入の目安

1回の釣りは、待ち時間の平均25秒、糸の張りの約9秒、釣果を見せる2.5秒を足して約37秒。1時間に約95回投げ、8割ほど釣れるとして約75匹になる。

| 釣りレベル | 1匹の期待値（海） | 1時間（餌代 約3,800円を引く） |
| --- | --- | --- |
| 1〜4 | 約380円 | 約2.5万円 |
| 30 | 約750円 | 約5.2万円 |

低位の職（約3万円/時）より少し低い。ミニゲームで1回が長くなったぶん、スキルチェックの頃（Lv1 約3.3万円、Lv30 約7万円）から下がった。低すぎるなら `Config.WaitMs` を縮める。高すぎるなら、`Config.Grades` の `perLevel` か、エピック・レジェンドの価格を下げる。成功率と1回の時間は仮の値なので、実機で測って直す。

## 導入

1. このフォルダを `resources/[standalone]/ta-fishing` に置く（`design/` と `tests/` は無くても動く）。
2. `install/ox_inventory-items.lua` の中身を `ox_inventory/data/items.lua` の末尾の `}` の前に貼る。
3. `install/images/` の PNG 15枚を `ox_inventory/web/images/` にコピーする。
4. `server.cfg` で ox_lib、ox_inventory、ox_target、oxmysql、qbx_core、okokNotify のあとに `ensure ta-fishing` を足す。
5. 再起動して、漁師から竿と餌を買って試す。

ox_inventory を新しい版に差し替えると、`items.lua` への追記と画像は消える。そのときは 2 と 3 をやり直す。

## 設定

設定はすべて `config.lua` にある。よく触るものは次のとおり。

| 項目 | 内容 | 初期値 |
| --- | --- | --- |
| `Config.Npc.coords` | 漁師の位置と向き。z は地面に合わせ直す | デル・ペロ桟橋 |
| `Config.Shop.items` | 店の品と値段 | 竿 15,000円、餌 40円 |
| `Config.SellAccount` | 売上の受け取り先 | `cash` |
| `Config.WaitMs` | アタリまでの待ち時間 | 15〜35秒 |
| `Config.HourlyCap` | 1時間の上限 | 150匹 |
| `Config.Grades` | グレードの重み、レベル補正、解放レベル、経験値、魚の強さ（`reel`）とレベルでの軽減（`eased`） | 上の表 |
| `Config.Reel` | 糸の張りの共通の値（時間切れ、最短の時間、張りの動き、暴れる合図の長さ） | 25秒、2.5秒、合図0.6秒 |
| `Config.ResultShowMs` | 釣果をガイドに出しておく時間 | 2.5秒 |
| `Config.UiScale` | 画面の大きさ（縦1080pxでの倍率。ほかの解像度では画面の高さに合わせて自動で拡大・縮小） | ガイド 1.3、漁師の画面 1.0 |
| `Config.Fish` | 魚、グレード、海か淡水か、相場の範囲 | 13種 |
| `Config.Market` | 相場の間隔、揺れ幅、売ったときの下がり幅 | 20分、±8%、0.3% |
| `Config.Weather` | 天候ごとの待ち時間の倍率、釣れない天候 | 雨0.75倍、雷雨は不可 |

## アイテム画像

`design/gen.js` が SVG を作り、`design/render.py` が headless Chromium で PNG にする。512px で描いて 256px に縮めたものを `install/images/` に入れている。絵を直すときは `gen.js` の魚の数値（体の高さ、ひれ、色、模様）を変えて、次を実行する。

```bash
node design/gen.js design/svg
py -3 design/render.py design/svg <出力フォルダ> <一覧画像.png>
```

右下のひし形がグレードの色（コモン灰、アンコモン緑、レア青、エピック紫、レジェンド金）。エピックとレジェンドには後光が付く。一覧は Claude Design のキャンバス「tani-fishing 魚アイコン」に置いた。

## テスト

`tests/` に、FiveM の関数を疑似した Lua のテストがある。fengari（JavaScript で動く Lua 5.3）で動かす。

```bash
npm i fengari luaparse          # 作業用のフォルダで
node tests/check.js .           # 構文、BOM と CR、知らないグローバル
node tests/run-test.js . tests/test-server.lua   # サーバー 82件
node tests/run-test.js . tests/test-client.lua   # クライアントとサーバーを直結、NUI は疑似 36件
node tests/test-reel.js .                        # 糸の張りの釣り合い（自動プレイヤー）26件
```

2026-11-11 時点で、すべて通っている。疑似環境なので、ネイティブ関数の実際の挙動（水面の判定、アニメ、竿の位置、NPC の出現）と、FiveM の中での NUI の表示は確かめていない。NUI の見た目はブラウザの見本で確かめた。

## 実機で確かめること

- 漁師 NPC が桟橋の上に正しく立つか。座標は目安で入れている。
- 竿の持ち方（`Config.Anim` の bone、offset、rotation）。左手に持つ設定にしている。
- 桟橋の上、岸、川辺、アラモ湖で水面が見つかるか。海と淡水の分かれ方。
- 糸の張りの難しさと、1回の釣りにかかる時間。左クリックとスペースが巻くに効くか。収入の表を実測で直す。
- ガイドが他の HUD（ox_inventory のホットバー、速度計など）と重ならないか。重なるなら `style.css` の `.guide` の `bottom` を変える。
- 漁師の画面で、魚の絵（`nui://ox_inventory/web/images/`）が出るか。Esc で閉じてゲームに戻れるか。
- 店で銀行払いになるか（このサーバーの useBank 改修）。
